
# DSA in Java

This repository documents my journey of learning
Data Structures and Algorithms in Java from the fundamentals.

## My Approach

- Learn DSA concepts from the basics
- Learn one pattern at a time
- Solve multiple problems using each pattern
- Understand why the pattern works
- Compare brute-force and optimized approaches
- Analyze time and space complexity
- Document key learnings and mistakes
- Implement solutions in Java

## Patterns

- Arrays
  - Two Pointers
  - Sliding Window
  - Prefix Sum
  - Hashing
  - Binary Search

- Strings
- Linked List
- Stack
- Queue
- Trees
- Graphs
- Dynamic Programming

## Goal

Build strong problem-solving skills through consistent,
pattern-based DSA practice in Java.
