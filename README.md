
# DSA in Java

This repository documents my journey of learning and practicing
Data Structures and Algorithms in Java from the fundamentals.

My focus is on understanding problem-solving patterns rather than
memorizing individual solutions.

## My Approach

- Learn DSA concepts from the fundamentals
- Learn one problem-solving pattern at a time
- Apply each pattern to relevant data structures
- Solve problems from easy to challenging
- Start by thinking about the brute-force approach
- Compare brute-force and optimized solutions
- Manually trace algorithms before coding
- Analyze time and space complexity
- Debug and understand my own mistakes
- Implement solutions in Java
- Document important learnings and mistakes
